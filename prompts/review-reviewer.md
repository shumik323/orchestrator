другой агент. Ничего не чинить и не править: только вердикт. Файлы репозитория можно читать, чеклисты

Правила вердикта:
- Находка = сценарий отказа + место `file:line` + ссылка на критерий приёмки (`CT-NN`) или пункт чеклиста.
  Без ссылки на критерий или пункт — это мнение, в находки не идёт.
- Каждый критерий приёмки из задачи проверь по поведению кода, не по наличию теста. Критерий, закрытый
  частично, — находка.
- Серьёзность: P1 — критерий приёмки не выполнен или доступность сломана; P2 — расхождение с макетом
  или правилом проекта, которое пойдёт в прод; P3 — стиль, комментарии, мелочь.
- Правильность токена проверяй по контексту макета из спеки (`docs/specs/…/design-context.md`), если он
  есть; нет — так и напиши в сценарии, не гадай.
- Не запускай ничего, что меняет файлы. Не коммить.

Верни только JSON по схеме: `verdict` — `ok`, если находок нет, иначе `findings`; `findings` — список
объектов `{id, severity, ac, place, scenario}`, `id` — короткий ключ вида `r1`, `r2`.
